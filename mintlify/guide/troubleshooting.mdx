---
title: "Troubleshooting"
description: "Resolve setup, connection, and processing problems."
---

## My agent cannot install the skill

Use Node 20 or later and the current package in the [CLI reference](/guide/cli). The host must support local skills and running commands. Otherwise, read guides in the browser. Installation does not run a local processing server.

## Website sign-in did not connect my agent

Website and CLI sessions are separate. Run login, then sign in and select Connect agent in the browser. An expired authorization requires a fresh login. Never paste a password or token into chat.

## My book is still processing

The processing card updates as the hosted worker extracts the file and maps its chapters. You may leave and return. Failed jobs show Retry processing for the uploader. Duplicate uploads reuse the existing edition, including work already in progress. Upload processing is free.

## A guide needs a subscription or has no allowance left

Check Billing for the current period and remaining allowance. Creating a new guide requires an active $24/month plan. Up to 30 guides may be completed or in progress per billing month. Failed generation releases its slot. Removing a completed guide does not refund it. A checkout return page alone does not activate the plan; the service waits for verified payment.

## A book has no cover yet

A ready book remains readable while its illustration finishes. A cover failure does not invalidate its source text.

## My old private book is not on the public shelf

Existing private books and guides are not automatically published. They remain accessible through your profile. Previous prepaid receipts remain under Previous billing.

## The source is scanned or protected

Use a readable copy you are authorized to upload. Hosted PDF extraction can read scanned pages; DRM restrictions are not bypassed.
