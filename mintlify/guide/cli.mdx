---
title: "Skill commands"
description: "One skill, one hosted reading service."
---
Use the installed Answer with Books runtime. Run `--help` for commands supported by that version.

| Command | Purpose |
| --- | --- |
| `books` / `book ID` | Shared catalog, book introduction and chapter references |
| `guides` / `guides --mine` | Published guides or your creation history |
| `guide ID` | Original-text reading or processing progress |
| `create-guide "QUESTION" --request-key UUID` | Start a public guide proposal; reuse the key on retry |
| `confirm-guide ID --minutes 10\|25\|45` | Confirm books and reserve one guide allowance |
| `ask "QUESTION"` | Answer using existing guides and source references |
| `source ID --start-line N --end-line M` | Subscriber access to 1–500 original source lines |
| `upload FILE [...]` | Free public upload and hosted processing |
| `plan` | Subscription and remaining guides |
| `login` / `logout` | Browser sign-in or revoke access |

No local server, local book processing, per-book skill installation or source-file download is part of this workflow.
