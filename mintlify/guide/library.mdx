title: "Use your library"
description: "Ask questions naturally and retrieve only the book methods that matter."
---

Once connected, ask your agent:

```text
Use my books to help me divide responsibilities across a growing team.
```

The agent searches relevant chapter methods, reads the evidence, and applies useful ideas to your question. The agent you are using writes the answer; saved book skills are reusable instructions and references.

## One skill is enough

Keep the generic Answer with Books skill for a large library. You do not need to clone a repository or install every book. Individual book skills are optional for favorites and local use.

To install one, ask “Install the skill for this book.” A ready full-source package includes `SKILL.md`, chapter notes, glossary, patterns, cheatsheet, and source references. Some hosts discover newly installed skills on the next turn or in a new session.

## Hosted retrieval or local installation

Hosted retrieval is the default for a connected private library. Your agent asks the authenticated `book-library` endpoint for relevant methods and source excerpts, then applies that evidence to your task. The endpoint does not execute `SKILL.md` or write the final answer. You do not need to download each book.

“Download book & skill” saves a ZIP for backup or optional offline installation. It includes generated notes, the skill files and extracted source text for checking citations. Downloading the ZIP does not install the skill or change how hosted retrieval works.

A book generated entirely with your own agent remains local. Importing that finished package for hosted retrieval is not available yet; see [Generate with your own agent](/guide/own-agent).

## Public and private sources

Public recommendations can include books outside the catalog. When choosing a reading set, the agent should show the selection criteria and let you choose before starting a conversion.

Private search only uses your connected account's eligible books. Hosted semantic retrieval sends the search question to the configured embedding provider. Public CLI retrieval uses the bundled public corpus.

## Disconnect

Ask your agent to log out of Answer with Books. This revokes its account connection. Book skills already installed on your machine remain local files after logout.
