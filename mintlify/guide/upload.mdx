---
title: "Add a book"
description: "Free hosted processing into the shared library."
---
Choose **Add a book** on Books, or ask the Answer with Books skill to upload your file. PDF, EPUB, DOCX, DRM-free Kindle, HTML, RTF, Markdown and text files are supported, up to 500 MB each and 100 new uploads per account in a rolling 24-hour period (up to ten files per batch).

Uploading is free. Books and completed guides are public. Only upload material you can share. Original files remain in private storage; subscribers read original text through the skill without a file download.

The server checks file fingerprints before extraction and normalized text fingerprints afterward. An existing copy opens its saved book or joins its processing job. Different editions are not merged merely because their titles match.

All extraction and AI processing run on the hosted service. The processing card continues after you close the page. Once ready, the book has an introduction, a brief summary, and questions you can explore through guides. The full extracted source and chapter map remain stored for future readings.
