Hosted processing extracts the source and prepares it for generation. New work waits for your price approval before paid generation starts.

1. Review the quoted customer token rates and maximum additional spending amount.
2. Add funds to the same account if needed.
3. Approve the quote to start generation.
4. Check progress in your library or ask your agent for the book's status.

Once queued, generation runs on the service. You can leave the page and return later. A checkout redirect or deposit does not start a conversion by itself.

## What you receive

The result includes a readable book summary, main skill, chapter notes, glossary, patterns, cheatsheet, source references, and review findings. Hosted processing also attempts a cover. Ready text can be used while its optional cover is pending or has failed.

The source and generation requests are processed by the service's AI providers. Model source checks are fallible; use the references to verify important claims.

## Pause, cancel, and retry

Pausing keeps the current reservation. Cancellation settles usage already consumed and releases unused funds after active work finishes. Retrying settled work or a failed cover requires a new approved limit. A cover retry can run without regenerating the book text.

An unresolved usage receipt can leave billing under review. Do not start duplicate conversions to work around an unresolved job. [Read the billing rules](/guide/billing).
