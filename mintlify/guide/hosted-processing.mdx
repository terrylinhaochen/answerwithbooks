---
title: "How books become readings"
description: "Hosted extraction, model reasoning and original passages."
---
The website runs on GitHub Pages. Supabase in Northern Virginia stores private originals, extracted text, chapter maps, guide records and subscription allowances. A dedicated AWS worker in Ohio extracts uploaded books. Supabase Edge Functions and database queues handle model processing and guide generation.

Each new book produces a checked chapter map, an orientation and questions to explore. It does not generate a separate agent skill or a long essay. The original text is preserved with stable line coordinates.

For a guide, the model considers the shared book maps, nominates scenes, reads their original text, and proposes a connected reading. After book and length confirmation it selects continuous passages, writes context and transitions, and checks the finished guide against the originals. Exact excerpt text comes from the saved source coordinates, not model-generated quotations.

Keyword matching and vector similarity do not choose guide passages. Fingerprints only detect duplicate editions. There is one Answer with Books skill for uploads, guide creation and answers from guides.
