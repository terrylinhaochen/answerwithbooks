## Implemented in this working tree

- Multiple local files/folders/globs can produce one named guide.
- Managed combined-source processing keeps original-source maps and valid headings.
- Both routes use shared collection guidance, keep author/source disagreements separate, and retain collection titles.
- Private import carries and validates the source map; retrieval returns source attribution with methods/citations.
- Agent routing recommends managed generation and documents the unreleased BYOA sync boundary.

## Limits

Controlled responses test pipeline behavior, not model intelligence. Independent semantic judging, live hosted acceptance and fresh-session skill discovery are `not_run` in results.json. A complete parity claim would be false: the separate editorial reader pipeline remains open. External package import and syncing later local revisions to the hosted copy are out of scope. Local incremental updates are now regression-tested, including reuse of earlier notes/citations and updating the same installed skill. The broader design also records local analyze-only, explicit edition metadata, and imported-cover gaps.

The attached transcript is an upstream local book-to-skill experience. Its saved 808-pass report was inspected, not rerun or counted here. Multi-source support was requested separately and is tested with synthetic sources; the private Bennett modernization was not copied or uploaded.

Production changes remain gated by the earlier pending deployment approval. The implementation changes have not been committed, published as a CLI release, or deployed. The documentation-only update was committed and pushed as 8a7b7c9; https://docs.answerwithbooks.com/guide/combined-guides returned HTTP 200 with the new update instructions and release notice.
