## Dependency maintenance

`npm audit --omit=dev` still reports five findings across Astro, Sharp, esbuild and the typography/PostCSS dependency chain (one critical, one high, two moderate, one low). A major Astro upgrade remains open. This release must not be described as audit-clean.

The deployed website is static GitHub Pages: no Astro request server, server islands, or on-demand image optimizer runs there. Source inspection found no `astro:assets` image processing. The only `define:vars` use receives configured analytics IDs, not submitted source content. Typography parses repository CSS at build time. These observations limit the demonstrated production exposure; they do not eliminate the need to upgrade. Do not enable Astro server rendering or build-time processing of untrusted images before addressing the advisories.

Primary advisory references: [Astro AVIF processing](https://github.com/advisories/GHSA-26w7-cxv4-gfx2), [Astro define:vars](https://github.com/advisories/GHSA-j687-52p2-xcff). Do not use `npm audit fix --force` as a substitute for validating a major framework migration.
