# Reading-path covers

Generated with the built-in imagegen tool, one request per cover. Existing public guide and interview cover assets were visually inspected first. Each new image uses the same wide sticker-illustration direction; short titles are accessible HTML overlays, not generated lettering. The shared GuideCover component renders both guide and reading-path artwork. Website assets are 1536 × 864 JPEGs, encoded at quality 85 (about 39–72 KB each). Originals are 1672 × 941; the near-identical aspect ratio is preserved in the website layout. Each detail page also uses its cover for Open Graph sharing. Original PNGs remain in the generation output directory; the site uses compressed JPEGs in `public/reading-path-covers/`.
